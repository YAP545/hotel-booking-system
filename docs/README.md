# Project Documentation & Assets

This folder is reserved for system architecture diagrams, database ER (Entity-Relationship) diagrams, API specifications, and application UI screenshots.

## Folder Organization

- **`docs/architecture/`**: Place high-level system architecture diagrams and flowcharts here.
- **`docs/er-diagram/`**: Place database entity-relationship (ER) diagrams and schema visualizations here.
- **`docs/screenshots/`**: Place application UI screenshots (Dashboard, Timeline, Booking Modal, Checkout, Reports) here to embed in the main repository `README.md`.
